Graduation Capstone — “Do Dream” Interactive Instrument

Year
2019
Field
Mechanical engineering
Type
Undergraduate capstone (team)

Overview

Team capstone project — “Do Dream”, an interactive percussion instrument that turns light into sound. A light-sensing module detects input and drives a drum / percussion sound module, integrating sensing, actuation, and product design.

Key points

  • Two subsystems: a light-sensing part (senses input and triggers sound) and a sound part (drum / percussion output).
  • Built and validated a working prototype through light-check and sound-check tests, then completed a finished product.
  • Covered the full development cycle — concept, prototyping, integration, and live demonstration.
