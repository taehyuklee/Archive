Overview

Multiple overseas entities had each been operating their own VoC system and CI/CD environment independently. I participated in planning a unified platform that brings them all under a single governance (HQ standard), serving as Technical Architect (TA) throughout.

Key roles

  • Overall architecture & infrastructure design — led the software architecture and infrastructure layout for both dev and production servers, and personally configured the HQ-side Nginx reverse proxy.
  • Entity data integration (EAI) — owned the structure that consolidates each overseas entity's authentication servers and HR data into the HQ DB via EAI, coordinating directly with each entity's staff, and pre-building view tables so developers could use the data right away.
  • Network & security validation — drove the connectivity checks between entity networks and the HQ network and the security reviews from the HQ side, leading meetings with the HQ security team; surveyed and consolidated each entity's document encryption/decryption (DRM) solution usage.
  • Deployment infrastructure on the closed development network — personally built Nexus Repository, Atlassian products, etc.; configured Red Hat 9.4 RPM packages and resolved OS-version compatibility issues.
  • Jira integration — negotiated API access with the Atlassian product owners and coordinated/implemented the integration between the IT-VoC system under construction and Jira as the person in the middle.
  • Ready-to-code developer enablement — communicated with the outsourced developers to provide an environment where they could start developing immediately, delivered technical guidelines, and designed dev-environment workarounds for authentication-server mismatches plus a migration plan for production.
  • Performed end-to-end TA duties — technical communication with the client, requirements analysis, and deployment-strategy design.

개요

여러 해외 법인이 각자 VoC 시스템과 CI/CD 환경을 독립적으로 운영하고 있었다. 이를 하나의 거버넌스(HQ 표준)로 통합하는 단일 플랫폼 기획에 참여했고, 전 과정에서 Technical Architect(TA) 역할을 수행했다.

주요 역할

  • 전체 아키텍처 및 인프라 구성도 설계 — 개발 서버와 운영 서버 양쪽의 소프트웨어 아키텍처와 인프라 구성을 설계하고 주도했으며, HQ 측 Nginx 리버스 프록시 구성도 직접 수행.
  • 법인 데이터 통합 (EAI) — 각 해외 법인의 인증서버와 인사정보를 EAI 를 통해 HQ DB 로 모아오는 통합 구조를 담당. 법인별 담당자와 직접 소통하며 진행하고, 개발자들이 바로 활용할 수 있도록 view table 을 사전 구성.
  • 네트워크 및 보안 검증 주관 — 법인 망과 HQ 망 간 통신 가능 여부 확인과 보안 점검을 HQ 측에서 주관하고, HQ 보안정보팀과의 회의를 주도. 법인별로 문서 암호화/복호화(DRM) 솔루션 사용 현황을 조사하고 취합.
  • 개발망(폐쇄망) 배포 인프라 직접 구축 — Nexus Repository, Atlassian 제품군 등을 구축하고, Red Hat 9.4 RPM 패키지 구성 및 OS 버전 호환성 문제 해결.
  • Jira 연동 — Atlassian 제품 담당자와 협의해 API 를 개통하고, 구축 중인 IT-VoC 시스템과 Jira 간 연동을 중간에서 조율하고 구현.
  • 개발자 즉시 투입 환경 제공 — 아웃소싱 개발자들과 소통하며 바로 개발 가능한 환경을 구성해 제공하고 기술 가이드라인 전달. 인증 서버 불일치에 대한 개발 환경 우회책 설계 및 운영 배포 마이그레이션 계획 수립.
  • 고객 기술 커뮤니케이션, 요구사항 분석, 배포 전략 설계 등 end-to-end TA 업무 수행.
